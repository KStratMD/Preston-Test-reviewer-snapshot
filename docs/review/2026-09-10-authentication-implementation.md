## Implementation

BaseConnector owns the public boolean authentication method, private state and shared pending promise. Fifteen direct subclasses implement protected hooks. The scoped ordinary/sensitive probe methods use the existing Axios transports, retry policy and breaker, without entering authentication. Base ensure rejects false and checks freshness. Request generations constrain 401 invalidation and replay, including transient attempts. Initializers reject mutation during authentication and invalidate derived caches on permitted reconfiguration. Pinned SuiteCentral keeps its separate client, sealed initialization and no-replay policy.

Legacy business-operation fixtures seed authentication through the public lifecycle with a temporary hook stub; they do not write private state. Authentication regressions use actual hooks and transport adapters. Public getSystemInfo remains an authenticated business path even when its URL matches the probe URL.

Two implementation-discovered corrections are within the approved boundaries: sensitive interceptors now log status instead of arbitrary error text, and seven demo-capable connectors recalculate mode when initialized again so prior demo success cannot bypass replacement credentials. Both have reproductions. Existing connector statuses and vendor-evidence levels are unchanged. Fixture credentials and adapter responses do not establish live vendor acceptance.
